### Technical Stack

* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
* **UI Engine:** Material 3 Design System with [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display) typography.
* **Key Libraries:**
    * `flutter_bloc` - For scalable and predictable state management using the BLoC pattern.
    * `dio` - For robust and flexible HTTP networking with interceptors.
    * `go_router` - For declarative, type-safe navigation and deep linking.
    * `cached_network_image` - For efficient image loading and caching.
    * `carousel_slider` - For smooth, interactive image carousels on the home screen.
    * `pinput` - For seamless and secure OTP/Verification fields.
    * `image_picker` - For profile photo selection from camera or gallery.
    * `shared_preferences` - For local data persistence (auth tokens, user info).
    * `flutter_svg` - To ensure high-quality, scalable vector graphics across all devices.
    * `lottie` - For lightweight, high-quality animations.
    * `shimmer` - For elegant skeleton loading placeholders.
    * `smooth_page_indicator` - For polished page indicator dots.
    * `readmore` - For elegant "Read more" / "Show less" expandable text handling.
